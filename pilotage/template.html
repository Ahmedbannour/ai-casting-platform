    Où en est le projet, et qui travaille dessus

    Au centre, le projet. Autour, les départements, puis leurs agents. Un halo animé signale un agent qui travaille en ce moment ; le chiffre indique ses tâches ouvertes. Cliquez un département pour le déplier, un agent pour voir ses tâches. Molette pour zoomer, glisser pour déplacer.

    Le parcours obligatoire de chaque prompt

    Aucun prompt n’arrive directement aux équipes : la Cellule IA le reformule et prépare les outils, puis la Direction le découpe en tâches. Cliquez une étape pour voir qui intervient et ce qui s’est passé pour le prompt choisi.
